One task group, one bead. Group 1 is the identity lookup and pull requests — the GitHub loader learns PRs and the store learns to answer a loader's cross-references; group 2 is commits in the git loader; group 3 is the two relation labels, the dogfood that merges the repository's two nodes and reads the interleaved timeline, and the follow-ups. All three build on the `timeline-view` branch (stacked; this change lands after it). Every group ends with `pnpm check` green. Test fixtures are scoped by a unique external-id prefix per test, never a store-wide count (`bd memories test-no-run-opened-assertions`).
